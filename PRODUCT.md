# Product

## Register

product

## Purpose

Help ordinary visitors understand sperm movement, anatomy, and DNA.
Use one live microscope sample with native mouse interaction.
Keep the first useful action visible without a tutorial.
Show defects directly in the live sample.
Open a moving detail popup when the visitor selects a cell.

The lab includes 12 independent factor sliders.
All sliders remain visible and act on the same synthetic population.
Every factor explains its mechanism, timescale, evidence, and limits.

## Users

Visitors explore the lab on a phone or laptop.
Developers install the npm package in their own sites.
Use the public package name `@esmirnov.ai/sperm-lab`.
The package needs no backend or account.

## Principles

Keep movement, vitality, shape, and DNA damage separate.
Use Explore to follow a swimmer with normal clicks or taps.
Show head, tail, and midpiece differences explicitly.
Include all 18 selected morphology, injury, and movement examples.
Show small, large, tapered, and round heads.
Show bent, coiled, short, absent, double, and triple tails.

Show the simulation as a teaching example, without clinical predictions.
Explain uncertain evidence near the factor controls.
Keep source links near each factor.

Keep the teaching population on by default.
Keep a matching example for every catalog category.
Let the factor controls act on the sample through illustrative channels.
Describe the catalog as selected teaching examples rather than clinical prevalence.
Use red fragmentation marks inside the compact nucleus for model DNA damage.

Combine factor controls without a dropdown or a baseline comparison.
Use a prepared morphology sample to teach separate cell traits.
Do not assign one unusual form to one lifestyle factor.

## Live inspection

Keep the selected cell and its popup visible during motion.
Show all cell traits in the popup.
Keep the full anatomy view optional.
Support selection through a visible head, midpiece, or tail.
Preserve keyboard inspection and popup dismissal.

Show Concentration as the current count in cells per model field.
Update that count with the current synthetic population.
Keep clinical units and diagnostic thresholds out of the readout.

## Release

Keep the core independent of React and browser globals.
Support React 18.2 through React 19 for the component.
Publish the package and the standalone demo from the same source.
Use the package API in the personal landing site.
